# OverRoot Builds

Playtest builds of OverRoot. Current build: **v1.6**

## How to playtest

1. Go to the [Releases page](https://github.com/J-Acklen/OverRoot_Builds/releases/latest) and download the file for your platform:
   - **Windows:** `OverRoot-v1.6-Windows.zip` — unzip and run `OverRoot.exe` (use `OverRoot.console.exe` to see a log window)
   - **Linux:** `OverRoot-v1.6-Linux.tar.gz` — extract with `tar -xzf OverRoot-v1.6-Linux.tar.gz`, then run `./OverRoot.sh`. If needed: `chmod +x OverRoot.x86_64 OverRoot.sh`
   - **macOS:** `OverRoot-v1.6-Mac.zip` — unzip and open the app (you may need to right-click > Open the first time)
2. New builds show up as new releases. Click **Watch > Custom > Releases** on the repo to get notified.
