# OverRoot Builds

Playtest builds of OverRoot. Current build: **v1.4** (in `Live_Build/v1.4/`).

## How to playtest

1. Clone the repo: `git clone https://github.com/J-Acklen/OverRoot_Builds.git`
   (the download is a few hundred MB, so it may take a minute)
2. Open `Live_Build/v1.4/` and pick your platform:
   - **Windows:** run `Windows/OverRoot.exe` (use `OverRoot.console.exe` to see a log window)
   - **Linux:** run `Linux/OverRoot.sh` (or `./OverRoot.x86_64`). If needed: `chmod +x OverRoot.x86_64 OverRoot.sh`
   - **macOS:** unzip `MacOS/OverRoot.zip` and open the app (you may need to right-click > Open the first time)
3. To get new builds later: `git pull`
